mend is one command-line tool that applies AI-written edits in four formats — unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of text files. It finds the lines an edit names at the first of three matching tiers (exact, trailing whitespace, full trim with re-indent), and changes every file or none: a failed edit is reported and nothing is written. Node 22, standard library only.

## Run it

```sh
node main.ts fix.patch
```
